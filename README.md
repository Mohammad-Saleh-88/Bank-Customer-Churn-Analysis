# Bank Customer Churn Analysis

## Project Overview
This project analyzes customer churn in a bank using Microsoft Excel. The goal is to understand customer attrition across demographic and banking segments and identify practical opportunities to improve customer retention.

The project includes a prepared Excel report and a dashboard that summarizes key customer and churn metrics.

## Dashboard Preview

![Bank Customer Churn Dashboard](Dashboard-Preview%20.png)

## Dashboard Highlights
The Excel dashboard presents 9 charts and key performance indicators, including:
- Total number of customers
- Average customer age
- Customer churn rate
- Average inactive months
- Average customer service calls
- Average credit utilization ratio
- Average transaction amount
- Average transaction count
- Average spending change
- Customer distribution by gender and churn status

It also visualizes churn patterns by:
- Age group
- Income range
- Marital status
- Credit card type
- Gender
- Education level

> Note: The dashboard is a static Excel dashboard; it does not contain interactive slicers or filters.

## Data Preparation
The case study documents data cleaning and transformation steps, including:
- Handling missing values in age, income, education, and inactive months
- Standardizing marital-status and gender values
- Correcting a credit-limit value using revolving balance and available credit
- Removing duplicate records, extra spaces, and unnecessary symbols
- Adjusting data types
- Adding `Churned` and `Age Range` columns

## Key Performance Indicators
The analysis tracks 10 KPIs:
1. Total number of customers
2. Number of male and female customers
3. Average age
4. Number of churned and existing customers
5. Churn rate
6. Average inactive months
7. Average customer service calls
8. Average credit utilization ratio
9. Average total transaction amount
10. Average spending change

## Recommendations
The case study proposes:
- Treating the third customer-service call as a trigger for proactive follow-up, with escalation at the fifth call.
- Re-engaging customers who are not using their cards or credit, and responding to sharp declines in transaction activity with reminders, incentives, or product reviews.
